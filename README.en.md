## 👋 About

I build the things I want to use, and I start by making them work.

Bots that run around the clock, apps that live on my phone, tools that make my own work easier —
the clearer the use case, the more fun it is to build, and the longer I keep improving it.

- 🤖 Discord bots (community management, text-to-speech, automation)
- 📱 Android apps (practical, fully offline)
- 🖥️ Windows desktop apps / an IME
- 🧰 Developer tools (a code editor, among others)
- 🛡️ Disaster information (earthquakes, tsunamis, weather)
- 🌐 Web services (published on Vercel)

## 🧭 How I Build

> **Idea → Build → Run → Try → Improve**

- Get something working first, then improve it while using it
- Keep tests and automation in place so "it still works" is verifiable
- Ship finished work as releases people can actually use
